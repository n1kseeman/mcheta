# Мцхета

Авторский сайт грузинского ресторана в Москве. Дизайн в первую очередь для MacBook и настольных экранов: винный бордо, сливочная бумага, грузинские мотивы, оригинальные SVG-иллюстрации, выразительная типографика и реальные фотографии кухни.

**Сайт:** https://n1kseeman.github.io/mcheta/

## Запуск

Node.js 20+, без установки зависимостей:

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. `npm run check` проверяет синтаксис, `npm run build` собирает статический сайт в `dist/`. Для публикации достаточно статического хостинга. GitHub Pages публикуется из `main`, корень репозитория.

## Что работает

- Семь категорий, 34 блюда с фотографиями, ценами и весом, подробные карточки.
- Бронирование по настоящему телефону ресторана. Сайт не отправляет заявки и не имитирует их подтверждение.
- Доставка через карточку ресторана в Яндекс Еде, маршрут через Яндекс Карты.
- Плавная навигация, появление секций при прокрутке, параллакс и hover-анимации.
- Семантическая разметка, клавиатурная навигация, нативные модальные окна и Escape, поддержка `prefers-reduced-motion`.
- Локальные фото WebP и шрифты. Нет трекеров, cookies и внешних запросов при открытии страницы.

## Файлы

- `index.html` — разделы, SVG-символы, модальные окна, метаданные.
- `styles.css`, `fonts.css` — дизайн и локальные шрифты.
- `menu.js` — данные блюд, категории и ссылки на фотографии-источники.
- `app.js` — фильтры, карточки, диалоги и анимации.
- `server.mjs` — сервер для локального просмотра; `build.mjs` — статическая сборка.
- `.codebase-memory/graph.db.zst` — сохранённый граф Codebase Memory.

## Источники

Данные получены 15 сентября 2026 года:

- https://mtskheta.ru/ — название, адрес, телефон, время работы, банкеты и терраса.
- https://eda.yandex.ru/r/mcxeta?placeSlug=mcxeta_kerchenskaya_1b_eiqsz — фотографии, названия, цены и вес блюд. Цены доставки могут отличаться от ресторанных.

Фотографии предоставлены в рамках задачи по редизайну, права остаются у их правообладателей. Маркетинговые тексты и декоративная графика созданы для концепции. Изображение города — стилизованная иллюстрация, а не карта расположения ресторана. Cormorant Garamond и Manrope распространяются по SIL Open Font License; лицензии находятся в `licenses/`.

## Codebase Memory

Проект индекса: `mcheta`, режим `full`, persistence включён. Для переноса используйте сохранённый артефакт; для обновления — `index_repository` с путём текущего checkout. Перед структурным поиском используйте граф, проверяйте покрытие через `check_index_coverage`. Фотографии и шрифты не индексируются как исходный код; `dist/` исключён как копия сборки.
